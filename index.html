// 05. GUIA TÁTICO & ROADMAP

COMO CRIAR PROJETOS QUE REALMENTE CONTRATAM

O que recrutadores técnicos e Tech Leads buscam em estudantes de Ciência da Computação.

01

Fuja dos Projetos "Clichê" e Genéricos

To-do lists simples, clones de tela estáticos e calculadoras não chamam a atenção de recrutadores. Em vez disso, construa aplicações com problemas reais: autenticação robusta (JWT/Cookies HttpOnly), persistência em banco relacional, paginação eficiente e tratamento de erros com logs.

Dica de Ouro: Implemente sempre um CRUD com pelo menos uma relação 1:N ou N:N e regras de validação consistentes.
02

Engenharia, Testes & Arquitetura

Como estudante de Ciência da Computação, seu grande diferencial é saber como o código funciona por trás dos panos. Organize seu backend em camadas (Controllers, Services, Repositories), aplique princípios SOLID e adicione testes automatizados (unitários e de integração).

Dica de Ouro: Adicionar 5 a 10 testes com Jest ou PyTest no seu projeto já coloca você à frente de 90% dos concorrentes a estágio.
03

O README Campeão que Tech Leads Leem

Recrutadores e líderes técnicos raramente rodam seu código localmente se for complicado. Seu repositório no GitHub precisa ter um README profissional com: GIF animado da aplicação funcionando, diagrama de arquitetura, decisões técnicas justificadas e comando `docker compose up`.

Dica de Ouro: Escreva um parágrafo "Principais Desafios & O Que Aprendi". Tech Leads amam ver capacidade de resolução de problemas!
04

Deploy Funcional & Ambientes Cloud

Um projeto com link de demonstração rodando online multiplica suas chances de ser chamado para entrevista. Use plataformas gratuitas ou freemium para hospedar seu frontend (Vercel, GitHub Pages), backend (Render, Railway, Fly.io) e banco de dados gerenciado (Supabase, Neon).

Dica de Ouro: Crie um pipeline no GitHub Actions para testar seu código a cada commit automaticamente.
